## 结论

- 27/27 个站内功能页均有同目录测试套件，完整性测试会从 `toolCatalog` 反查并阻止漏测。
- 共 30 个测试文件（27 个功能套件 + 1 个完整性套件 + 2 个公共能力套件），183 条测试。
- 不访问真实网络、相册、用户文件或小程序跳转；时间、随机数、Taro 存储、Canvas 和导出流程均为确定性模拟。
- 外部 `shortLink` 民生服务、新手指南、首页和搜索页未纳入。
- 当前覆盖率：statements 93%+、lines 96%+、functions 96%+、branches 82%+，高于 85/85/85/75 门槛。
- `document-copy` 已置于推荐工具与热门工具首位。
- `document-copy` 已拆到专属普通分包；构建实测主包 0.47 MiB、原工具分包 0.70 MiB、证件排版分包 0.50 MiB、总产物 1.67 MiB，均通过包体门禁。

## 政策与业务口径限制

- BMI 采用国家卫健委成人标准阈值；儿童、孕产妇、运动员等特殊人群不适用。
- 工资工具保持“单月静态估算”，不模拟年度累计预扣、奖金、补税/退税和地方社保基数上下限。
- 养老金只验证全国通用数学公式与个人账户计发月数；当地计发基数、过渡性养老金、视同缴费和地方细则仍以当地人社部门为准。
- 退休年龄覆盖普通职工渐进式延迟退休规则；特殊工种、病退、灵活就业和地方办理细则未建模。
- 房贷结果不包含银行按日计息、提前还款、利率重定价日和各银行尾差处理。
